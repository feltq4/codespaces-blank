# Extra Night Vision (Fabric, Minecraft 26.2)

Client-side hitbox resizer. It has NOTHING to do with night vision; that is just the name.

- Keybinds (change them in Options > Controls > Key Binds, category "Extra Night Vision"):
  - Open menu: Right Shift
  - Toggle enlarged hitboxes: H
- Commands: /friend add <name>, /friend remove <name>, /friend list  (friends are kept in memory only)
- Settings are saved in .minecraft/config/extranightvision.json
- Needs: Fabric Loader 0.19.3+, Fabric API for 26.2, Java 25.

## How the jar is built
Push this project to GitHub. The file .github/workflows/build.yml builds it automatically.
Download the jar from the "Releases" page (release named "Latest build") or from the Actions run (Artifacts).
